First tagged release of kide: the kreatos Neovim setup, packaged to build **offline from source** on RHEL9. The build never touches the network; `vendor/` holds source only (no binaries, no upstream `.git*`).

## What's in it

- **Neovim v0.12.5** with its bundled deps, built from source
- **Plugins** at pinned commits (`manifest/plugins.tsv`), loaded as opt packages; treesitter parsers compiled at build time
- **C/C++:** clangd (RHEL), neocmakelsp v0.11.0, clangd_extensions, cmake-tools, neotest-gtest, neogen, nvim-dap with gdb / lldb-dap
- **Python:** ruff + ty 0.15.11, debugpy 1.8.21 (via `kide-python`)
- **Terminal tools:** fish 4.9.3, fzf v0.74.4, lazygit v0.65.1, yazi v26.1.22 (with the `search-jump-legacy` and `fgo-legacy` plugins), shfmt v3.13.1
- **Podman image** that can be built on top of the ibn-dev build environment; shell hooks in `/workspace/.container/{bash,fish}`, history and git identity kept in the workspace
- **Remote use:** PuTTY session (`putty/kide.reg`) and Windows Terminal profile (`windows-terminal/kide.json`, OSC 52 clipboard)

## New in this release

- **nvim hooks:** every `/workspace/.container/nvim/*.lua` is sourced in name order after kide's config (directory overridable with `$KIDE_NVIM_HOOKS`; the image ships none)
- **AI chat (gp.nvim):** chat and in-buffer rewrite/append/implement against any OpenAI-compatible chat-completions endpoint, configured only from a hook (`require("misw.ai").setup{…}`). No tool calling needed. All gp.nvim built-in providers, voice and image generation are off by default, so nothing is sent anywhere unless a hook names an endpoint. Keymaps under `<leader>a`. See README → "AI chat (gp.nvim)".

## Install

See the README: one-call install, offline install from the tarball (this release's *Source code (tar.gz)*), or the podman image.

## Known limitations

- This release was not re-verified with a fresh image build and the full `test/run.sh`. gp.nvim and the nvim hooks were tested against an older image with the new config mounted in.

Full component list with upstream URLs and pins: `VERSIONS` and README → "Third-party software".
